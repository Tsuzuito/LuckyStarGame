
# Lucky Star Game

A small meme game written in Java using Swing for educational purposes. It was inspired by a [funny image](https://github.com/user-attachments/assets/82216d59-5b6c-489f-bb04-72ebf8694a51) I saw somewhere on Telegram. Original project, inspiration: [**BounceRika**](https://github.com/Nyuke235/BounceRika)

The program (will) feature 4 mini-games (Snake, Space Invaders, Memory Cards, Paddle Game) in the style of the anime Lucky Star, a scoring and save system, visual and sound design, and more!

The goal of the project is simply to learn something new and make something fun :p
